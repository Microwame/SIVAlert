# API
## Como iniciar a API:
1. Instale o python 3.15 em https://python.org/downloads
2. Vá à pasta e faça um venv com este comando na powershell:
```bash
$ python -m venv .venv
```
3. Ative o venv com este comando na powershell:
```bash
$ .venv\Scripts\Activate.ps1
```
4. Instala os pacotes necessários com:
```bash
$ pip install -r requirements.txt
```
5. Inicie o servidor iniciando o script "start.py":
```bash
$ cd API
$ .\start.py
```
